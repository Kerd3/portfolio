01 / OVERVIEW

A full marketing site for a fictional product.

NexusAI is a fictional AI-powered product workflow platform used as the subject of a frontend landing-page concept. The repository contains a responsive, static marketing experience. It should be read as a UI and interaction project, not as a working AI platform or backend service.

02 / PAGE EXPERIENCE

A product story with working navigation.

The site includes a hero, feature grid, how-it-works section, integrations, pricing tiers, testimonials, signup call to action, and secondary informational pages. Hash-based routing handles the secondary views without a backend. The sticky navigation and layout adapt to mobile, tablet, and desktop screens.

03 / INTERACTIVE PRICING

A pricing calculator that responds.

The pricing calculator supports a seat slider from 1 to 100, a monthly/annual toggle, a 20% annual discount, a live total, and a plan recommendation across Starter, Pro, and Enterprise. The signup call to action provides a local demonstration state; it does not collect or persist a real email submission.

04 / IMPLEMENTATION

Browser-native, with no build step.

Semantic HTML5Vanilla CSSVanilla JavaScriptHash RoutingResponsive Layout

The project is implemented with static HTML, CSS custom properties, Grid and Flexbox, and vanilla JavaScript. The repository README reports no external runtime dependencies or build step.

05 / SCOPE & LIMITATIONS

A concept, not a real AI integration.

The landing page markets a fictional product. It does not include an AI backend, real integrations, live billing, a CRM, or server-side signup. The integrations and customer sections are part of the frontend concept and should not be read as active third-party connections or real customer endorsements.
